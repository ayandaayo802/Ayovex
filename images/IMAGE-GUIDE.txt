-----------------------------------------------
  IMAGE TIPS
-----------------------------------------------

  - Use high-quality, well-lit photos
  - Show your best work first
  - Consistent editing style across all photos
  - Square crops work best for the portfolio grid
  - Avoid watermarked images
  - Use compressed JPGs for fast loading
  - Recommended max file size: 300KB per image
  - Tools to compress: tinypng.com or squoosh.app
